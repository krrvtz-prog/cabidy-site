# cabidy-site

Páginas públicas do TapLook (privacidade, termos, suporte), publicadas pelo GitHub Pages.
Este repositório precisa ser público para o GitHub Pages gratuito funcionar. Não coloque nada privado aqui.

- `.well-known/security.txt`: contato para relatar falhas de segurança. Renovar a data `Expires` todo ano (vence em 30/09/2027). O `_config.yml` faz o GitHub Pages publicar essa pasta.
- Política e Termos existem em português e inglês (`en/`): toda mudança vai nas duas versões ao mesmo tempo.
